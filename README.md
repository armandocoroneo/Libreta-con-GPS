# Libreta GPS

Libreta GPS es una aplicación Android diseñada para repartidores, vendedores y técnicos que necesitan guardar la ubicación exacta de sus clientes.

## Características

- 📍 Guardar ubicación GPS
- 👤 Nombre del cliente
- 📝 Descripción
- 📷 Foto opcional
- 🔍 Búsqueda rápida
- 🗺️ Abrir en Google Maps o Waze
- 🌙 Tema oscuro
- 🔠 Letras grandes
- 📶 Pensada para funcionar con pocos datos
- 💾 Base de datos local (SQLite)
